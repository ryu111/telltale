# band：共同規則（每張票都適用，票裡不重複）

- SDD：`docs/SDD.md`。票只寫「對應哪一節」，定義以 SDD 為準；票與 SDD 衝突以 SDD 為準並回報。
- 產品是 TypeScript plugin（`hooks/`）。程式碼與註解**英文**；不裝任何 npm 相依（`bun test` 內建，型別在 `.claude/types/claude-code.d.ts`）。
- 型別只讀票「相關檔案」指到的行段，不要整份讀 `.d.ts`（8,752 行）。
- 驗收測試：`.test.ts`／`.test.tsx` 用 `bun test <路徑>`；`.py` 用 `uv run pytest <路徑>`。`tests/` 與 `hooks/*.test.ts*` 是出題者的，實作不改；覺得題目錯寫在回報 `stuck`。
- 每張碰 `hooks/*.ts` 的票要在 `hooks/mutations/NN-<slug>.json`（一票一檔） 寫進自己的 `hooks/mutations/NN-<slug>.json`（票裡列出 label／old／new）；`make mutate` 全紅才算完。`old` 必須在檔案裡恰好出現一次。
- 完成條件一律：`make check` 全綠（ruff＋mypy＋pytest＋`bun test hooks/`＋`claude plugin validate --strict .`）。
- `$` 只准 `$.ui.resolve`、`$.ui.invalidate`、`$.clock.now`、`$.clock.every`、`$.store.get`、`$.store.set`、`$.command.register`（SDD §1.4）。多一個就是錯，validate 的 `calls:` 會抓。
- 面板（`hooks/panels/*.ts`）與純函式（`width.ts`、`layout.ts`、`hit.ts`、`command.ts`）**不 import `claude-code`、不碰 `$`**。
