# band：共同規則（每張票都適用，票裡不重複）

- SDD：`docs/SDD.md`。票只寫「對應哪一節」，定義以 SDD 為準；票與 SDD 衝突以 SDD 為準並回報。
- 產品是 TypeScript plugin，本體在 `plugins/telltale/`（`hooks/…` 都相對它）；bun 測試與 harness 在 `tests/hooks/`；突變清單在 `tests/突變/NN-<slug>.json`。程式碼與註解**英文**；不裝任何 npm 相依（`bun test` 內建，型別在 `.claude/types/claude-code.d.ts`，2.1.274 產、12,243 行、不進 git）。
- 型別只讀票「相關檔案」指到的行段，不要整份讀 `.d.ts`。
- 驗收測試：`.test.ts`／`.test.tsx` 用 `bun test <路徑>`；`.py` 用 `uv run pytest <路徑>`。`tests/` 是出題者的，實作不改；覺得題目錯寫在回報 `stuck`。
- 每張碰 plugin `.ts`／`.tsx` 的票要把突變寫進自己的 `tests/突變/NN-<slug>.json`（`file` 相對 repo 根，如 `plugins/telltale/hooks/cells.ts`）（一票一檔）（票裡列出 label／old／new）；`make mutate` 全紅才算完。`old` 必須在檔案裡恰好出現一次。
- 完成條件一律：`make check` 全綠（ruff＋mypy＋pytest＋`bun test tests/hooks/`＋`claude plugin validate --strict plugins/telltale`＋marketplace validate）。
- `$` 只准 `$.ui.resolve`、`$.ui.invalidate`、`$.ui.open`、`$.ui.close`、`$.clock.now`（**async**，要 await）、`$.clock.every`、`$.store.get`、`$.store.set`、`$.command.register`、`$.agent.list`、`$.env.get`（SDD I12）。多一個就是錯，validate 的 `calls:` 會抓。hooks 只准 I12 列的事件；絕不 `tool.call`／`classic.*`。每個 hook 一律 `return next(e)`（I13）。
- 面板（`hooks/panels/*.ts`）與純函式（`width.ts`、`layout.ts`、`hit.ts`、`command.ts`、`cells.ts`）**不 import `claude-code`（type import 可以）、不碰 `$`**。
- 2.1.274：Client 用 `module="./band.tsx"`（相對路徑字面值）；hooks.json 沒有 `surface`；Promise 進 Client props 會被拒繪。
- v0.2 的長相以 `docs/DESIGN.md` 與 `docs/設計/試衣間.html`（Version 10 的 JS 是同一套規則的可執行參考，可以照抄邏輯，但輸出改成 Text 元素）為準。
