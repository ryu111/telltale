## 題目
主 agent 在 2.1.274 真機（`/telltale agents size full`、派一個 30 秒的 Explore subagent）看到動畫全部成立（spinner、方框鏈、`◉` 目前節點、`◆···` 光點、跑馬燈、`✓` 完成），但有五個要修：
1. **cell 跨 session 殘留**：`agents.cells` 在 `$.store`，新 session 一開就看到上一個 session 的 `✓ main 44m23`。`session.start` 時把 `agents.cells` 清成 `{}`（新 session 沒有舊任務可看；bg 任務也隨舊 session 消失）。
2. **帶屬性的通知標籤**：`turn.start.text` 是 `<agent-message from="…">` 這種帶屬性的標籤時，`descOfTurn` 沒認出來（只認 `<xxx>`）。改成 `^<([a-z-]+)(\s|>)` 抓標籤名 → `↩ agent-message`。
3. **空 cell**：subagent 結束後多出一列 `✓ sub 0s · `（label `sub`、desc 空、0 秒）。找出來源（很可能是 `agent.list` 的 poll 對一個已結束、沒 description 的 entry 重新開了 cell，或 task-notification 開了 bg cell）並堵住：**沒有 description 的 AgentInfo 不開新 cell**，通知只關 cell 不開 cell。
4. **main 歷史合併列**：目前把合併 cell 當一般 cell 畫（方框鏈裡一排 `turn`）。合併 cell（`MAIN_HISTORY_ID`）在任何樣式都只畫 `renderMainHistory` 那一列，不畫節點。
5. **agents 預設全展**：`Panel` 加 `defaultStage?: Stage`；agents 面板 `defaultStage: "full"`；`register.tsx`／`command.ts` 讀 `size.<id>` 缺省時用 `p.defaultStage ?? "compact"`（demo 面板維持 compact，票 11 的測試不動）。
