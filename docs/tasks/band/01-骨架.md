## 題目
給一個 `--plugin-dir` 指到本 repo 的 session，要得到：`claude plugin validate --strict --json .` 成功、`calls:` 只含白名單、輸入框上方出現一行 `telltale · maxRows=<N> · viewport=<columns 或 none>`。

細節：
- `.claude-plugin/plugin.json`：`name: "telltale"`, `version: "0.1.0"`, `description: "A live status band for Claude Code."`, `author: { "name": "ryu111" }`, `userConfig: { "panel.hello": { "type": "boolean", "title": "Hello panel", "description": "Show the hello panel", "default": true }, "panel.clock": { … "default": true } }`。
- `hooks/hooks.json`：`{ "modules": ["register.tsx"], "surface": "band.tsx" }`。
- `hooks/register.tsx`：`export const register: Register = (on) => { on("ui.render", { component: "AbovePrompt" }, ($, e, next) => { … }) }`；`e.surface !== "terminal"` 或 `e.props.hasSurvey` 就 `return next(e)`；否則 `const { Box, Text } = $.ui.resolve(e)` 畫一個 `Box` 裡一個 `Text`，內容就是上面那行（`viewport` 沒有就印 `none`）。這張票**只**呼叫 `$.ui.resolve`。
- `hooks/band.tsx`：只需 `export function Band(props: unknown, surface: ClientSurface) { const { Text } = surface.elements; return <Text>telltale</Text>; }`（型別 `import type { ClientSurface } from "claude-code"`）。這張票的 register 還不畫 `Client`；檔案存在是為了讓 `hooks.json` 的 `surface` 有東西指。
- `tsconfig.json`：照型別檔檔頭那份，`include: [".claude/types", "hooks"]`。
- `Makefile` 的 `check` 最後加一行：`CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1 claude plugin validate --strict .`。

不要做：layout、面板、store、command——那是後面的票。
