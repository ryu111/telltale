## 題目
agents 每秒 poll，末列永遠是 `updated 0s ago`，沒有資訊。使用者裁定：**狀態列只在有事（`dropped` 非空或有面板 `error`）時出現**，平常那一列還給面板內容。

### layout.ts（純函式）
```ts
export const BAND_ROWS_MAX = 9;
export const TITLE_ROWS = 1;                              // band 標題列，永遠在
export const STATUS_ROWS = 1;                             // 狀態列，有事才在
export const FIXED_ROWS = TITLE_ROWS + STATUS_ROWS;       // 狀態列出現時的固定列數（既有名字保留）
export const CONTENT_ROWS_MAX = BAND_ROWS_MAX - TITLE_ROWS; // 8：沒有狀態列時內容最多幾列
export type Layout = { slots: Slot[]; dropped: string[]; total: number; status: boolean };
export const layout = (panels: readonly Want[], maxRows: number, opts?: { status?: boolean }): Layout;
```
- `opts.status === true`（框架在有面板 error 時傳）→ 固定列 = `FIXED_ROWS`，`status: true`。
- 否則先用固定列 = `TITLE_ROWS` 算一次；**有任何面板進 `dropped` 就改用 `FIXED_ROWS` 重算一次**（狀態列要印 `⋯ x not shown`），`status: true`；沒有 dropped 就 `status: false`。兩次都是同一套規則 1–6，只有固定列數不同。
- 規則 2（`budget < 1`）：一定有東西被砍，所以固定列 = `FIXED_ROWS`，`total = max(1, min(maxRows, FIXED_ROWS))`，`status: true`。
- `panels.length === 0` → `{ slots: [], dropped: [], total: 1, status: false }`。
- 規則 5 變成 `total = (status ? FIXED_ROWS : TITLE_ROWS) + Σ (PANEL_TITLE_ROWS + slot.rows)`。
- `rowsForStage("full").wantRows` 仍是 `CONTENT_ROWS_MAX`（現在是 8）。

### register.tsx
- `buildBandProps` 在呼叫 `layout` **之前**先讀每個 active 面板的 `error.<id>`，`layout(wants, maxRows, { status: anyError })`；`BandProps` 多一個 `status: boolean`（`hit.ts` 的型別加上），照 `layout().status` 傳。`command.run` 那條 `layout(wants, BAND_ROWS_MAX)` 同樣傳 error 旗標。

### band.tsx
- 只有 `props.status` 為 true 才 `rows[total - 1] = statusLine(...)`；`statusLine` 拿掉 `updated Ns ago` 分支（沒事就不會被叫到；被叫到但沒 dropped 也沒 error 時回空字串）。`total === 1` 分支不變。`BandProps.now` 保留（cells 動畫用）。

### README
- 「Default height is 7 rows」那句改成：agents 面板單獨、full 時 `TITLE_ROWS (1) + (1 title + 7 rows) = 9`；狀態列只在有面板因高度被砍或出錯時出現、佔 1 列。
