## 題目
給面板清單 `{ id, minRows, wantRows }[]` 與 `maxRows`，回 `{ slots, dropped, total }`，照 SDD §1.2 七條規則；匯出常數 `BAND_ROWS_MAX = 9`、`FIXED_ROWS = 2`、`CONTENT_ROWS_MAX = BAND_ROWS_MAX - FIXED_ROWS`（**用減法算出來，不寫第二個數字**）、`MIN_COLUMNS = 20`。`panels` 為空回 `{ slots: [], dropped: [], total: 1 }`。純函式、不 import `claude-code`。

突變（寫進 `hooks/mutations/NN-<slug>.json`）：
1. label `layout: total cap ignores BAND_ROWS_MAX` — `Math.min(maxRows, BAND_ROWS_MAX)` 改成 `maxRows`。
2. label `layout: dropped panels are not reported` — 把塞不下的面板推進 `dropped` 那行改成不推。
3. label `layout: half a panel is drawn` — 面板拿不到 `minRows` 時仍給它剩下的列數（而不是整個不畫）。
