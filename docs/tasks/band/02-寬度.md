## 題目
給任意字串，`displayWidth` 回終端顯示欄數（SDD §1.3 的寬字表算 2、控制字元算 0、其餘 1）；`fit(s, columns)` 在 `displayWidth(s) ≤ columns` 時**原樣回傳**，否則裁到 `≤ columns` 並以 `…`（1 欄）結尾、不切半個寬字；`columns ≤ 0` 回 `""`。純函式、無相依、不 import `claude-code`。

突變（append 進 `hooks/mutations.json`，`old` 抄你程式碼裡真實的那段，必須恰好出現一次）：
1. label `width: wide chars count 1` — 把寬字算 2 的那個分支改成算 1。
2. label `width: fit truncates a string that already fits` — 把「放得下就原樣回傳」的判斷改成永遠裁。
3. label `width: fit cuts one column too many` — 裁切預算少 1。
