## 題目
`/telltale agents edge` 目前只寫 store、什麼都不會變（`register.tsx` 只讀來顯示）。而且現在 Pane 與 AbovePrompt 兩個 render site 各畫各的，同一條帶子出現兩次（票 16 實測）。改成三態，指令與按鍵同一個鍵。

### 語意（`edge.agents`，沒存視同 `right`）
| 值 | `session.start` | `ui.render{AbovePrompt}` | `ui.render{Pane}` |
|---|---|---|---|
| `right` | `$.ui.open({ id: "telltale", title: "telltale" })` | `return next(e)` | 畫全部面板 |
| `bottom` | 不 open | 畫全部面板 | `return next(e)` |
| `both` | open | 畫 **agents 以外**的面板；沒有就 `next(e)` | 只畫 `agents` |

- 切換（`command.run` 的 `agents edge <v>` 或 `ui.message { kind: "edge" }`）：寫鍵 → 新值是 `bottom` 就 `await $.ui.close({ id: "telltale" })`，是 `right`／`both` 就 `$.ui.open(...)`（重複 open 只是重送 title，型別檔 `PaneOpenArgs.id` 說明）→ `$.ui.invalidate("ui.render")`。
- `buildBandProps` 多收 `only?: "agents" | "others"` 過濾 `active`（layout 也只算被畫的那些）。
- `command.ts`：`AgentsView.edge` 加 `"both"`；`agents edge both` 合法；`top`／`left` 仍 `not available in this build`。`agents edge` 報目前值（沒存報 `right`）。
- `hit.ts`：`TitleButtons.edge` 有值時帶子多一組 `[R B RB]`（在 `[S C F]` 之後、`[x]` 之前）；`R` → `{ kind: "edge", id, value: "right" }`、`B` → `bottom`、`RB`（兩字元加右邊一格）→ `both`；active = 相等。`register.tsx` 組 `buttons.edge` 為目前值。
- `band.tsx`：不用改邏輯（畫與命中都從 `buttonStrip` 來），只確認 `RB` 兩字元的 span 畫對。

### README
- 「引擎只給右側 dock 與輸入框上方兩個位置」改成三態說明：`right` (Pane; the engine docks it beside the transcript from ~110 columns and drops it above the prompt when narrower), `bottom` (the AbovePrompt band only), `both` (agents in the Pane, every other panel above the prompt). top/left are not positions the engine offers.
- `validate` 輸出重貼（`calls:` 多 `$.ui.close`）；「Why `$.ui.open` shows up」那段補 close 一句。

突變：
1. label `right still draws above the prompt` — `right` 時 AbovePrompt 不 `next(e)` 照畫。
2. label `both still puts agents above the prompt` — `both` 時 AbovePrompt 沒過濾掉 agents。
3. label `bottom does not close the pane` — 切到 `bottom` 時不呼叫 `$.ui.close`。
