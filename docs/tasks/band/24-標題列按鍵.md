## 題目
使用者在帶子上找不到換模式的按鍵（只有 `/telltale agents style` 指令）。做成標題列上可點的字：`[1 2 3]`（v1／v2／v4）、`[S C F]`（summary／compact／full）、`[x]`（clear）。另外 DESIGN §4「貼側邊→v2、貼上下→v1」一直沒實作（`register.tsx` 兩處預設一個 `v1` 一個 `v2`，指令報的跟畫的不一樣），一併修成依 placement。

### hit.ts（純函式，畫與命中的唯一座標來源）
```ts
export type TitleButtons = { style: "v1" | "v2" | "v4"; size: Stage; edge?: "right" | "bottom" | "both" }; // edge 這票不畫（票 27）
export type ButtonMessage =
  | { kind: "style"; id: string; value: "v1" | "v2" | "v4" }
  | { kind: "size"; id: string; value: Stage }
  | { kind: "clear"; id: string }
  | { kind: "edge"; id: string; value: "right" | "bottom" | "both" };
export type ButtonSpan = { x0: number; x1: number; text: string; active: boolean; message: ButtonMessage }; // x1 含
export type ButtonStrip = { x0: number; text: string; spans: ButtonSpan[] }; // text 是整條，如 "[1 2 3] [S C F] [x]"
export const buttonStrip = (id: string, buttons: TitleButtons, label: string, columns: number): ButtonStrip | null;
export type TitleClick = ButtonMessage | { kind: "stage" | "toggle"; id: string } | null;
export const resolveTitleClick = (y: number, x: number, props: BandProps, columns: number): TitleClick;
```
- `BandPanel` 加 `buttons?: TitleButtons`（只有 agents 面板有，`register.tsx` 組）。
- 帶子文字：組出現順序 `[1 2 3]`、`[S C F]`、（`buttons.edge` 有值才有 `[R B RB]`，這票不會有）、`[x]`，組之間一個空白。每顆按鍵的 span = 那個字元加它右邊一格（`1` 佔 `x, x+1`；`RB` 佔兩字元加右邊一格）。`active`：style 組 = `buttons.style` 相等；size 組 = `buttons.size` 相等；`x` 永遠 false。
- 位置：右對齊，`x1 of 整條 = columns - TITLE_RESERVE - 1`；`x0 = 那個 - displayWidth(text) + 1`。若 `x0 < displayWidth("─ " + label + " ─") + 1` 回 `null`（放不下整條就不畫，不畫半條）。
- `resolveTitleClick`：`hitPanel(y, x, props, columns)` 為 null → null；命中的面板有 `buttons` 且 `x` 落在某個 span → 那個 span 的 `message`；否則 `{ kind: titleClickKind(id, props), id }`。`hitPanel` 本身不改。

### band.tsx
- 有 `buttons` 的面板，標題列改成 spans：前段 `panelTitleLine(label, columns)` 的前 `strip.x0` 個字元（tone 照舊），接著帶子：active 的字元 tone2 `white`（＝粗體），其他字元 `grey`，`[`／`]`／空白 `greyDeep`；帶子後面到 `columns` 補 `─`（tone 照舊）。`strip` 為 null → 標題列跟現在一模一樣。

### register.tsx
- `buildBandProps(active, $, maxRows, viewportColumns, placement: "dock" | "inline")`：AbovePrompt hook 傳 `"inline"`；Pane hook 傳 `e.props.placement`（型別檔 `Pane.placement: 'dock' | 'inline'`，2.1.274）。agents 面板的 `style`：`store.get("style.agents")` 是 `"v1"|"v2"|"v4"` 就用它；沒存或 `"auto"` → `placement === "dock" ? "v2" : "v1"`。`BandPanel` 加 `buttons: { style: <生效值>, size: <目前 stage> }`。
- `ui.message` 新增三種：`isStyleMessage` → `$.store.set("style.agents", value)`；`isSizeMessage`（面板要有 stages，沒有就忽略）→ `$.store.set(\`size.${id}\`, value)`；`isClearMessage`（id 必須是 `agents`）→ 讀 `agents.cells`，`clearDismissable(cells)`，寫回。三種都 `$.ui.invalidate("ui.render")`。
- `command.run` 的 `agentsView.style` 改成 `store 值 ?? "auto"`。
