# 08-寬度實測（手動，主 agent 做；不進跑票）

- 對應 SDD 節次：切片層 #8；不變量 I4、I11；DoD #4
- 可碰檔案：`scripts/量寬度.sh` `docs/實測/寬度.md`
- 驗收：腳本對 `w ∈ {200,150,110,80,60,45,30}` 每步 resize、等 3 秒、capture 帶子那幾列，量每行顯示寬度 ≤ w、且至少一行面板內容；`w=15` 只剩一列且 debug log 沒有 `does not validate|hook failed|refused`。結果表貼進 `docs/實測/寬度.md`。
- 依賴（Blocked by）：06
- 為什麼不進跑票：要開真的 claude + tmux，30 秒以上、依環境；不是單元測試。

## 做法
```bash
tmux new-session -d -s tt -x 200 -y 34 -c "$PWD" "CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1 claude --plugin-dir $PWD --debug-file /tmp/tt.log"
sleep 15
for w in 200 150 110 80 60 45 30 15; do
  tmux resize-window -t tt -x $w -y 34; sleep 3
  tmux capture-pane -t tt -p > /tmp/tt-$w.txt
  # 帶子 = 輸入框上方連續的那幾列；用 uv run python 量 wcwidth（東亞寬字算 2）
done
grep -iE "does not validate|hook failed|refused" /tmp/tt.log
```
