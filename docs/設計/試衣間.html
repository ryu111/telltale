一個 cell 一個任務，cell 裡動態長出流程圖，鏡頭跟著走

同一段模擬：main 這一輪做事（思考 → 工具 → 思考 → 工具…），中途派出 subagent，每個 subagent 是一個新 cell，用一模一樣的表示畫它自己的流程。光點的規則改成你說的：只有 A → B 那一條在 B 抵達前（0.6 秒）有光點流動，光點到了、B 確定收到，光點停止、B 亮起、A 壓灰；其他連線靜止。另外：節點打字機、目前節點呼吸、完成的 cell 三秒後收成一列、新 cell 滑入。顏色改成一套：綠＝進行中、藍＝細節／時間、琥珀＝main、紫＝subagent、紅＝失敗、灰階三級＝過去式。

自適應：貼在畫面四邊任一邊，樣式可切

模擬 150×40 的終端。top／bottom／left／right 四個按鈕決定 mod 貼在哪一邊（每一邊都有自己的收合），V1+V4／V2+V4／V4 決定 cell 長相；兩組互相獨立，任何樣式都能放任何一邊。「開合」拉到底就是把整個高度或寬度交給面板。未來新的 mod 一樣用這四邊。


  
v1 · 方框節點，跑馬燈鎖右（原 V1＋V4）
第一列照 v4：分隔線＋標題＋任務名稱（main 是這輪的 prompt，subagent 是它的 description；太長就跑馬燈）；底下三列是方框鏈，最新節點鎖在右側、舊的往左流；完成後只剩第一列。

  
v2 · 直管線，最新節點鎖底（原 V2＋V4）
標題列只放名字、模型、時間；任務名稱換到 cell 內第一行，整行寬度都給它，還是放不下就跑馬燈；直管線，最新節點永遠在 cell 最底一列，舊的往上推；完成後縮成窄直欄。

  
V1 · 橫向流程，鏡頭水平跟
cell 是一條橫向的軌，節點左→右長出來（方框從一點展開），連線上光點帶尾巴流向目前節點；超出 cell 寬度時整條往左滑。cell 上下堆疊，完成的收成一列。

  
V2 · 縱向流程，鏡頭垂直跟
cell 是一根直的管線，節點由上往下長，連線上光點往下流、到達時目前節點亮一下；超過高度時往上捲。cell 左右並排。

  
V3 · 蛇形折行，鏡頭跟最新一行
節點左→右，滿一行折到下一行接著長（轉角也走光點），鏡頭只在行數超過 cell 高度時往上捲。cell 並排成格子。

  
v4 · 兩列跑馬燈
第一列是分隔線＋任務名稱（名字、模型、時間、這個任務是什麼），第二列是壓成一條鏈的流程，最新節點鎖在右側、舊的往左流；完成後只剩第一列。


  

  

    
動態清單（全部共用）事件到：先在 A → B 的連線上跑 0.6 秒光點（B 先以 `·` 佔位）；抵達：光點停、B 亮起（白粗體＋淡綠底、邊框呼吸）、名字逐字打出、A 與它的框壓灰；cell 完成：標題打 ✓、3 秒後收成一列摘要、60 秒後消失；失敗：節點 ✗、cell 邊框紅、底色淡紅、留到點掉。

    
鏡頭每幀往目標位移 12%（ease-out）；新 cell 從右緣滑入 0.5 秒。

    
真機限制subagent 內部的工具事件要靠 `turn.step` 帶 `agentId`；若實測拿不到，subagent 的 cell 只有 spawned → running → done 三個節點。底色（tint）要看 Text 的 backgroundColor 是否可用（型別檔有）。
