### 評測法（每條品質條件對一種；出處：platform.claude.com/docs/en/test-and-evaluate/develop-tests）
| 品質在問什麼 | 評測法 | 住哪一層 |
|---|---|---|
| 答案是固定類別／固定值 | exact match（正規化空白與大小寫後比對） | 單元或流程，無 LLM |
| 同義輸入要得到一致答案 | cosine similarity（embedding 相似度） | 評測 |
| 摘要有沒有抓到重點、順序對不對 | ROUGE-L 對參考摘要 | 評測 |
| 語氣、風格、同理心這類主觀程度 | LLM Likert 1–5 | 評測 |
| 有沒有含某類內容（洩漏個資、禁用詞） | LLM binary | 評測 |
| 有沒有用到給的 context、多輪一致 | LLM ordinal 1–5 | 評測 |

規矩：評分模型 ≠ 生成模型；案例量勝於質（幾十到幾百條自動評，勝過幾條人工評）；案例集一定放邊界案例（空輸入、超長輸入、模稜兩可、惡意輸入）；沒有 3～5 個「這算好／這不行」的參考樣本就等於沒定義。
